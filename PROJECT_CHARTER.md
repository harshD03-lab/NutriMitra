## Purpose & Goals

**Purpose:** To develop an AI-powered personalized diet recommendation system that provides users with custom meal plans, nutritional tracking, and health insights.

**Goals:**
- Provide a user-friendly interface for dietary tracking and meal planning.
- Allow users to input personal health metrics, preferences, and dietary restrictions.
- Provide automated, AI-driven diet and nutrition recommendations.
- Maintain user profile, history, and calorie intake logs.
- Manage users, system data, and nutritional guidelines through an Admin Panel.
- Develop a scalable and maintainable system using modern web technologies.

## In Scope
- User registration, login, and account management.
- User profile and dietary preference management.
- AI-based diet recommendation engine.
- Meal tracking and calorie calculation logs.
- Dashboard for daily nutrition history and status.
- Admin Panel for users, nutritional data, and system settings.
- Frontend development using modern web/mobile frameworks.
- Backend API development.
- Database integration.
- Application deployment.

## Out of Scope
- Clinical medical diagnoses or prescription treatments.
- Real-time video consultations with certified dietitians.
- Integration with external hospital ERP systems.
- International multi-currency grocery ordering integration.

## Technologies Used
- **Frontend:** React Native / React / TypeScript / HTML / CSS / JavaScript
- **Backend:** FastAPI / Node.js / Express.js
- **Database:** MySQL / PostgreSQL
- **Tools:** VS Code, Git, GitHub
- **Deployment:** Railway / Cloud platforms
